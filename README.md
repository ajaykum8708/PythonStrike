# 🎮 PythonStrike - Learn Python by Shooting

**PythonStrike** is an interactive Python learning game built with **Python and Pygame**.

Instead of learning Python only through theory, players learn programming concepts by answering questions, shooting correct answers, completing levels, and defeating bosses.

> 🎯 **Learn Python. Shoot Answers. Become a Python Master.**

---

## 🚀 Features

* 🎮 Interactive shooting-based Python learning game
* 🧠 Python programming questions
* 🎯 Shoot the correct answer
* ❌ Wrong-answer detection
* 🏆 Score system
* ❤️ Health system
* 🔫 Shooting mechanics
* ⏱️ Timer-based gameplay
* 💡 Hint system
* 👑 Boss battles
* 📈 Multiple difficulty levels
* ⚡ Normal Mode
* 🔥 Advanced Mode
* 🎓 Teacher Special Mode
* 🔊 Sound effects and background audio
* 🔄 Restart and revive system
* 🖥️ Resizable game window
* ⌨️ Keyboard controls
* 🖱️ Mouse controls

---

## 🕹️ Game Modes

### 🟢 Normal Mode

Normal Mode contains multiple Python learning levels covering fundamental programming concepts.

Players progress through questions and levels and eventually face the final boss.

### 🔴 Advanced Mode

Advanced Mode contains more challenging Python questions and programming concepts.

It is designed for players who already understand the basics of Python.

### 🟣 Teacher Special Mode

A special advanced learning mode containing challenging Python questions designed to test programming knowledge.

## 🎮 Controls

| Key / Input     | Action                |
| --------------- | --------------------- |
| 🖱️ Mouse       | Shoot / Select Answer |
| `1` `2` `3` `4` | Select Answer         |
| `H`             | Hint                  |
| `R`             | Revive / Restart      |
| `S`             | Speed                 |
| `M`             | Window Mode           |
| `E`             | Exit                  |
| `Ctrl + C`      | Control Panel         |
| `Ctrl + S`      | Change Speed          |

> Controls may vary depending on the current game mode.

## 💻 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/ajaykum8708/PythonStrike.git
```

### 2. Open the Project

```bash
cd PythonStrike
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Game

```bash
python strike.py
```

## 🎯 How to Play

1. Start the game.
2. Select a game mode.
3. Read the Python question.
4. Identify the correct answer.
5. Shoot the correct answer.
6. Earn points and progress through levels.
7. Use hints when needed.
8. Defeat the boss to complete the stage.
9. Improve your Python knowledge while playing.
